## 2. 项目背景与目标

### 2.1 业务背景

铂康医疗为 **42 家医院**（含院区拆分）提供器械消毒灭菌服务。各医院在合同条款、科室结构、物流模式、折扣政策等方面差异显著，业务人员每月需将系统「未改账单」手工加工为符合医院要求的「特色账单」，涉及删列、插列、改价、拆行、凑数、分科室汇总、结款函制作等大量重复劳动。

### 2.2 建设目标

| 编号 | 目标 | 说明 |
|:----:|------|------|
| G1 | 可配置化 | 任意医院可在客户管理中启用「特色账单」模式，无需改代码 |
| G2 | 规则引擎化 | 折扣、特殊计费、低消、物流、加急、分科室等业务规则可配置、可复算 |
| G3 | 流程一体化 | 特色规则嵌入「导入 → 对账 → 月度结算 → 多格式导出」完整链路 |
| G4 | 结果可解释 | 对账详情展示规则命中、多报价选择、费用调整原因 |
| G5 | 逐步替代手工 | 优先覆盖高频、规则相对稳定的医院，复杂医院分阶段交付 |

### 2.3 能力域与医院分级

系统覆盖 **10 大能力域**：折扣、特殊计费、低消/封顶、物流、导出、加急、科室借调/费用调整、花名册、外来器械、器械量表/日结。

| 级别 | 家数 | 代表医院 | 上线门槛 | 主要依赖模块 |
|:----:|:----:|----------|:--------:|--------------|
| **L1 首批** | 8 | 省二院南岗/松北、呼兰一院、红十字妇产、冰城医美 | Phase 3 后 | M1–M4 + 基础 M8 |
| **L2 第二批** | 12 | 呼兰中医、祖研三院区、太平人民、新发红十字 | Phase 4–6 | M5/M6 增强、导出折扣、加急 |
| **L3 第三批** | 6 | 市五院、市二院、省医院、国药总院 | Phase 7 | M10–M12 + 复杂 M8 |
| **L4 后续** | 4+ | 维多利亚、九州、远东、中医三院 | Phase 9 | 分温结款函/日结/审计 |

> **15 工作日冲刺范围：** 以 **L1 + L2 首批上线** 为目标；L3/L4 纳入 **Phase 2 滚动交付**（15 工作日之后）。

```
                                   └─────────┘（Phase 1–2 验收与 Phase 3 可部分重叠）
```

- **Phase 3 导出引擎** 为唯一硬依赖：M4（L1 门禁）之前不可跳过。
- Phase 1–2 验收与 Phase 3 后端骨架可在 Day 3–5 **并行**启动。
- 逐院规则录入（配置工作）与开发 **全程并行**，不占用开发关键路径。
