## 一、STD-09 在本手册中的形态

### 1.1 正文（冻结快照，2026-08-15）

```markdown
### STD-09 · 包名「针N」拆分规则

**作用**：包名形如「AR水管-2件/双/Z1530」中「针N」参与折算。
```

- 仅 **3 行**，无公式、无关键词白名单、无包类型门禁。
- 示例包名 **「AR水管」与「针N」无关**，属错误示例，会误导读者以为该规则与水管包有关。
- 与引擎实现一致处：确实对应 `PricingEngine` 中 `Pattern.compile("针(\\d+)")` 全串扫描——**该实现已被认定为非法全局规则**（见 `docs/祖研排针17全局针数量拆分误解析分析报告-20260916.md` v2）。

### 1.2 生成器中的硬编码（重跑会复活 STD-09）

`scripts/generate_billing_rules_handbook.py` **L446–448** 将 STD-09 **写死在模板字符串**中，**不**从 manifest 读取：

```python
"### STD-09 · 包名「针N」拆分规则",
"",
"**作用**：包名形如「AR水管-2件/双/Z1530」中「针N」参与折算。",
```

因此：**只要有人执行 `python3 scripts/generate_billing_rules_handbook.py`，STD-09 会再次写入文档**——与是否修正引擎无关。

### 1.3 关联非法条目：STD-08 表述亦不准确

同手册 **STD-08** 写「包名含针/小件/车针…」，而合法通用小件词表仅为 **8 个具名关键词**（`DefaultPricingTemplate`）。  
STD-08 与 STD-09 在文档结构上相邻，易让读者认为「任意含针包名」均应先走 STD-09 再走 STD-08——**与合法口径不符**。

## 二、系统更新规则时是否参考本手册？

### 2.1 运行时与 CI：**完全不参考**

| 链路 | 是否读取 `账单规则全览手册.md` |
|------|-------------------------------|
| `PricingEngine` / `DefaultPricingTemplate` | **否**（读 Java 模板与 DB 编译规则） |
| `billing-rules/baseline/*.json` → manifest | **否** |
| `baseline_to_manifest.py` / G1 闸门 | **否** |
| `hospital-cli rules verify --all` / G3 | **否** |
| GitHub Actions / `verify-billing-seed.sh` | **否**（已检索，无引用） |
| 部署 baseline-sync / reconcile | **否** |

**每次发版、规则 reconcile、manifest 写入均不依赖本手册。**

### 2.2 人工与辅助开发：**存在间接污染风险**

| 风险 | 说明 |
|------|------|
| 研发/AI 阅读 9600 行全览手册 | 可能按 STD-09、已删「校正价」CR 条 **错误实现或「修复」** |

| 与 `通用计价规则手册.md` 第五章「针N」**双源冲突** | 两处均描述非法规则，互相印证错误 |

### 2.3 本手册的生成方式（为何冻结在 8 月）

- 入口：`python3 scripts/generate_billing_rules_handbook.py`
- 数据源：**当时**的 `billing-rules-manifest.json` + **硬编码** STD-01～STD-12 模板

## 三、是否有更专业的替代文档？

**有。** 现行体系已拆分为「标准灭菌」+「院级特色」+「流程规范」三层，本手册为早期 **合并快照**，已被取代。

| 层级 | 权威/专业文档 | 生成方式 | 与运行时关系 |
|------|---------------|----------|--------------|
| **流程与闸门** | `docs/计费规则迁移与验收规范.md` | 人工维护 | G0–G4 强制流程；**未提及全览手册** |
| **标准灭菌（STD）** | `docs/通用计价规则手册.md`（2026-09-08） | 人工维护 | 描述 `DefaultPricingTemplate` 行为；**仍含非法「针N」第五章，须同步删除** |
| **院级特色（CR）** | `docs/医院特色计价规则清单.md` | `python3 scripts/billing_rules_catalog.py --write` 或 `./bin/hospital-cli rules doc` | **从 live manifest 生成**，带 hash 与时间戳 |
| **院级规则真源** | `backend/src/main/resources/billing-rules/baseline/*.json` | PR 编辑 + `baseline_to_manifest.py` | **唯一落库源** |
| **引擎真源** | `DefaultPricingTemplate.java`、`PricingEngine.java` | 代码 | 实际计价 |

**对照：**

| 能力 | 全览手册 | 替代方案 |
|------|----------|----------|
| 客户规则清单 | CR-001～300（**冻结**） | `医院特色计价规则清单.md`（**随 manifest 更新**） |
| 标准灭菌 STD | 第 2 章（含 STD-09） | `通用计价规则手册.md` + 源码 |
| SC11 业务分类 | 第 6 章 | 可保留为 `docs/通用计价规则手册.md` 附录或 `generate_billing_rules_handbook.py` 中 **仅导出 SC11 表** 的极小脚本 |
| 规则总量统计 | 第 0 章（**写死 300 条**） | manifest `rule_count` / `hospital-cli rules verify` |

**结论：全览手册无独立不可替代的技术作用；其职能已由上述文档覆盖且更新更及时。**

| 项 | 决定 |
