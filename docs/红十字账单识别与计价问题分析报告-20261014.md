# 红十字账单：医院名、科室栏、特殊计价

日期：2026-10-14  
文件：`红十字 (2).xlsx`（工作表 `DeliveryNoteSummaryWithPackingM`，9439 行，明细 9350 行）  
对照：`特殊收费(1).xlsx`「各医院特殊收费」第 178–184 行；客户档案 `HRB-HSZ`  
本报告只说明原因，不改规则、不改代码。

界面上这三件事是连着的。医院名被读成「额外包」之后，客户档案对不上，特色规则整本不会套上，顶部科室栏也还停在那一张英文工作表上。

---

## 1. 结论

**1. 医院名读错了，读成了「额外包」。** 这家表的医院全称写在表头下面的 A 列：`哈尔滨红十字妇产医院`。D8、D9 是空的。前端解析时丢掉了空行，固定去读的 D8 落到了明细行的「基本类型」列，格子里就是「额外包」。这个词又被当成合格的医院名。文件条上的「额外包」「未匹配到客户档案」「标准灭菌计费规则」就是这一步的结果。

**2. 顶部科室栏列的是工作表，不是表里的科室。** 全文件只有一张工作表。37 个科室写在 A 列，作为分组标题夹在明细中间。保存后表格里的「科室」列已经按这些标题拆开了，顶部标签仍只有「全部科室」和 `DeliveryNoteSummaryWithPackingM`。另外两个标题被丢掉了：`美容科（朝鲜医院）` 因为带「医院」，`生殖中心` 因为带「中心」，都被当成医院汇总行跳过。

**3. 特色规则在库里，但这张单没有用上。** `特殊收费(1).xlsx` 第 40 家「哈尔滨红十字医院」的四条规则已经在 `HRB-HSZ` 基线里。任务绑的是「额外包」，对不上 `HRB-HSZ`，所以走标准灭菌价。截图里 `额外包(ETO)`、300×320、1 件、账单 22.00、规则价 35.00，是低温 30cm 标准价，不是特色价漏算。特色规则「一件一包固定 22 元」若套上，这一行应保持 22.00。

---

## 2. 这张表长什么样

和常见的分科室铂康表不同。医院名不在 D8/D9，科室也不是一张表一个科室。

| Excel 行 | A 列 | D 列（基本类型） | 含义 |
|---|---|---|---|
| 1 | | | 标题在 B 列：发货单汇总表-显示包装材料 |
| 4 | | | B 列账期：从 2026/5/1 至 2026/10/13 |
| 8–9 | | | 包数合计、处理费用合计，不在 D 列 |
| 12 | 发货日期 | 基本类型 | 表头。列不连续，中间有空列 |
| 13 | 哈尔滨红十字妇产医院 | 空 | 全院汇总。包数 21854，总价 863590.5 |
| 14 | ICU病房 | 空 | 科室分组标题 |
| 15 起 | 2026-05-07 | 额外包 | 明细。类型在 E 列，如 额外包(ETO) |

表头实际列：发货日期、发货单号、基本类型、类型、包类别号、包名、包装材料、包数、器械数量、单价、总价。「器械数量」中间有换行，导入时会收成「器械数」。

A 列里不是日期的文字有 38 个，各出现一次：1 个医院名，37 个科室标题。明细 9350 行，和界面上的「9350 行明细」一致。

## 3. 医院名为什么是「额外包」

识别顺序是：先看固定的 D8、D9，有字就用；没有才沿「发货日期」列和 A 列找医院汇总行。

后端按 Excel 行号保留空行，D8、D9 确实是空的，下一步能读到 A 列的 `哈尔滨红十字妇产医院`。

前端用 SheetJS 读表时设置了 `blankrows: false`，整行空白会被抽掉。抽掉之后，原来的第 8、9 行不再是 D8、D9。固定下标 7、8 落到了前两行明细上，D 列恰好是「基本类型」，值是「额外包」。

D8/D9 的校验不要求格子里带「医院」。表头词、日期、纯数字、科室名会被丢掉，「额外包」不在这份排除名单里，于是被接受。

一旦这里有了结果，后面的 A 列医院名不再看。导入时这个名字又排在客户档案匹配之前：档案里没有「额外包」，内勤规范名也对不上，任务医院名就停在「额外包」。文件名 `红十字 (2).xlsx` 也组不出医院全称。

所以界面是：

- 医院徽章：额外包
- 未匹配到客户档案
- 计价范围：标准灭菌计费规则

表里的真名 `哈尔滨红十字妇产医院` 还没进入匹配。就算这一步改对，档案仍是精确相等，和现用名字对不齐：

| 来源 | 写法 |
|---|---|
| 这张账单 A 列 | 哈尔滨红十字妇产医院 |
| 客户档案 / 别名 | 哈尔滨市红十字妇产医院、红十字妇产 |
| 内勤基线 `customerName` | 哈尔滨市红十字中心医院 |
| 计费基线、特殊收费表 | 哈尔滨红十字医院 |

差在「市」，以及「妇产医院 / 中心医院 / 红十字医院」这几种叫法。别名「红十字妇产」按包含可以罩住账单上的全称，但现在名字在「额外包」这一步就停了，走不到别名。

---

## 4. 顶部科室栏为什么只有一张表

顶部标签来自前端解析出的工作表列表，不是保存后的科室列表。这个文件只有一张表，名字是英文的 `DeliveryNoteSummaryWithPackingM`。所以标签只有「全部科室」和这一张表，后面的 9350 是整表行数。

明细里的科室是另一条路。表头带「基本类型」，导入把它当成合并单。A 列上没有日期、没有单号、没有类型、没有包名的行，被当成科室标题，写进该段明细的科室字段。表格「科室」列因此能看到 ICU病房、分娩室、口腔科。顶部标签没有改成这些名字。点那张英文表去筛选时，筛的是工作表名，对不上已经拆开的科室名。

37 个标题里有 2 个不会变成科室：

- `美容科（朝鲜医院）`：文字里有「医院」，被当成医院汇总行跳过，后面的明细仍挂在上一个科室
- `生殖中心`：文字里有「中心」，同样被跳过

其余 35 个标题会成为科室。行数最多的是腔镜手术室 2684、手术室 1656、口腔科 885、计划生育 875、新生儿 784。

内勤规则里已经写过这句话：「导入的账单不是分科室账单，需要识别」。指的就是这种一张表里用 A 列分段的格式。规则本身没有列清单，识别靠上面的分段逻辑。顶部栏没有改用分段结果。

## 5. 特殊计价为什么看起来没生效

`特殊收费(1).xlsx` 第 178–184 行是这家医院，表上的医院名是「哈尔滨红十字医院」。规则已经在 `HRB-HSZ` 基线里：

| 特殊收费表 | 基线规则 | 口径 |
|---|---|---|
| 额外包低温等离子、额外包（ETO）、单包装（低温老肯）、单包装（EO），1 件 | 红十字一件一包固定22 | 固定 22 元，与包名无关 |
| 针盒-1/W6050，敷料包（无纺布） | 红十字针盒固定16.5 | 固定 16.5 元 |
| 包名称带「双」，额外包（纸塑袋），少于 3 件 | 红十字双&lt;3按件5.5加列出的袋 | 5.5×件数 + 列出的袋，封顶 16.5 |
| 同上，不少于 3 件 | 红十字双≥3按件5.5不加袋 | 5.5×件数，不加袋 |

任务医院名是「额外包」，匹配不到 `HRB-HSZ`，这四条都不会进入计价。界面上的「标准灭菌计费规则」是这个结果，不是规则没录入。

截图那几行对得上标准价，对不上特色价：

- `湿化瓶-1/Z3032`、`呼吸机湿化瓶-1/Z3032`：类型额外包(ETO)，材料高温纸塑袋 300×320，器械数 1，账单 22.00。标准低温 30cm 是 35.00，备注会写 30cm 阶梯。特色规则「1 件固定 22」套上之后应仍是 22.00。
- `简易呼吸器-1/Z3044`：同样是额外包(ETO)、1 件口径的 22.00 被标准价改成 35.00。材料是 300×440，也落在 30cm 以上这一档。
- 全表额外包(ETO)、器械数 1、单价 22 的明细有 532 行。它们都是同一类：账单已按 22 元，标准价会按袋尺寸改写。

`针类组件-15/Z7520` 不是这四条特色规则的范围。包名是「针类组件」，不是「针盒-1/W6050」，也没有「/双」。通用小件词（克氏针、车针等）也不含「针类组件」。高温纸塑、单包不少于 3 件时按实件×5.50、不再加袋：15×5.50=82.50。账单单价 16.50。两包时原总价 33.00、规则总价 165.00，差额 +132.00。这一行在医院名配对之后仍然走这条标准算法，除非另定针类组件的规则。

`针盒-1/W6050` 全表只有 1 行，类型敷料包，账单已经是 16.50，和特色固定价相同。`针导-1/双Z1029` 会在医院配对之后进入「/双」规则；现在因为整单没有绑到 `HRB-HSZ`，这条也没进。

---

## 6. 三件事要分开改

1. 医院名：空行不能把 D8/D9 挪到明细上；「额外包」这类基本类型不能当成医院名。A 列的 `哈尔滨红十字妇产医院` 要能对上 `HRB-HSZ`，账单写法比档案少一个「市」。
2. 科室栏：顶部标签要用 A 列分段得到的科室，不要只用工作表名。带「医院」「中心」的科室标题不能整段跳过。
3. 计价：特色规则不用改条文。医院名回到 `HRB-HSZ` 之后，1 件低温/ETO 才会固定 22 元。针类组件-15 的 82.50 是标准按件价，不在当前四条特色规则里。

---

## 7. 已落地

方案只动识别，不动 `HRB-HSZ` 四条特色规则，也不改基线 `customerName`。

1. **医院名。** 前端读表保留空行，D8/D9 不再被抽到明细。前后端都拒绝「额外包 / 器械包 / 敷料包 / 单包装包」。落到明细上的 D8/D9 丢掉，改用 A 列医院汇总行。本地档案当时没有「红十字妇产」别名，规范名还停在计费基线的「哈尔滨红十字医院」。启动时补上种子里已有的包含别名，并把规范名对齐为「哈尔滨市红十字妇产医院」。不改基线 `customerName`。
2. **科室栏。** 「美容科（朝鲜医院）」「生殖中心」当科室；整行「哈尔滨红十字妇产医院」仍是医院汇总。前端预览按 A 列分段出科室。保存后顶部标签改用后端 `sheetName` 分组，点击按科室筛选。
3. **计价。** 医院名回到 `HRB-HSZ` 后，额外包(ETO) 且器械数为 1 仍走「红十字一件一包固定22」。不新增针类组件规则，不给红十字新造内勤折扣。

本地导入 `红十字 (2).xlsx` 后：医院名「哈尔滨市红十字妇产医院」，科室 37 个（含 ICU病房、美容科（朝鲜医院）、生殖中心，不含医院全称），湿化瓶-1/Z3032 额外包(ETO)、器械数 1，规则单价 22.00，计价路径「红十字一件一包固定22」。
