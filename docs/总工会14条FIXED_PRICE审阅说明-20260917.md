## 审阅背景

- **NONE ≠ 无依据**：2026-09-02 用户上传 Excel 的「哈尔滨市总工会医院」段 ①-⑩ 有完整文字，已通过种子 `phase-special-charge-zgh-fixed-price-20260902` 落库；G4 院级 PASS 亦按该用户侧 Excel 验收。
- **仓库副本现状**：`特殊收费(1)`/`(4)` 中 HL-ZGH **仅有 5 行**指定镜头「标准价 +8 元」（EXTRA_FEE），**不含** ①-⑩ 固定价段。
- **计价模式**：`hybrid`。删除后对应包走 **标准灭菌阶梯价 + 包材费**，一般 **不等于** 固定价且多数 **偏高**（20260902 专报：清宫包等会从 35 元偏离为 43 或更高）。

### 决策选项

| 选项 | 含义 |
|------|------|
| **全部保留** | 与用户侧 Excel ①-⑩、20260902 专报、真实账单一致；仓库 Excel **滞后未同步** |
| **全部删除** | 与仓库 Excel 对齐，但妇科包/敷料很可能回到错误计价 |
| **同步仓库 Excel** | 把 ①-⑩ 补进 `docs/source/特殊收费(1).xlsx` → 14 条可从 NONE 变为 EXACT |

**共同技术属性**（14 条一致）：`FIXED_PRICE` + `skipPackaging=true` + `skipDiscount=true`；①-⑧ 为 **exact_token**；⑨⑩ 六条为 **contains**（W 码分档，与电机厂同形态）。
