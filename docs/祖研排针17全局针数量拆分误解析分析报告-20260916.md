| 项 | 内容 |
|----|------|
| **编制日期** | 2026-09-16（v2：按业务三条绝对判断重写） |
| **关联医院** | 祖研-黑龙江省中医医院（南岗院区）`ZUYAN-NG` |

## 〇、三条绝对判断（本文档前提）

### 判断一：包类型通道不可混淆

- **高温无纺布计费** 与 **高温纸塑袋（额外包）计费** 是两条独立标准路径，**不得混用**。
- 祖研院级特殊规则（`祖研排针10合1含/免包材`）的 `acceptedTypes` **仅** `额外包（纸塑袋）`；本例为 **器械包 + 无纺布** 时 **不命中祖研 FOLD 属于正常现象**。
- 客户处理后账单上的 **13.5 元** 来自纸塑袋/FOLD 或已删除的校正价口径，**不能作为无纺布器械包行的验收标准**。
- **但：当前系统算出 27.5 元仍然一定错误**——错误原因不是「没走祖研特色规则」，而是走了 **全局非法「针N」拆分**（见判断二）。

### 判断二：通用特殊计价不存在「任意位置 针+数字」规则

- 在 **通用（标准灭菌模板 `rules.needle`）** 口径下，**不存在**「在包名任意位置查找 `针+连续数字` 并折算」的合法规则。
- 该逻辑为 **STD-09 遗留非法实现**，须追查出处并与其他同源非法规则一并清除（见第四章完整清单）。

### 判断三：根治方案是删除非法规则，而非打补丁

- 2026-09-02「气腹针」排除、`W9050` 跳过、吸脂针长型号跳过等，均为 **在非法规则上叠补丁**，**不予认可**。
- **核心解法**：**永久删除**全局 `针(\d+)` 拆分整条分支；通用小件折算 **仅保留** 下列 8 个关键词的合法路径（`exact_token` + 5 合 1，及院级 FOLD 另行配置）：

  > 克氏针、银质针、内热针、车针、拔髓针、扩大针、根扩针、卷棉子

## 一、祖研样例：系统为何一定算错

### 1.1 行字段与应走路径

| 字段 | 值 | 含义 |
|------|-----|------|
| 包名 | `排针17/W6050` | 产品规格名（「17」= 排针规格，非「针类件数语法」） |
| 包类型 | **器械包** | 走 **高温无纺布** 标准通道 |
| 包材 | 无纺布-60x60-50g | 与纸塑袋无关 |
| 器械数 | 17 | Excel 计费基准（引擎注释：不从包名覆盖） |

**应发生：** 未命中祖研纸塑袋 FOLD → 按 **高温无纺布计费** 对 **17 件器械** 计价（例如 17×5.5=93.5，具体以无纺布阶梯/产品匹配为准）。

**实际发生：** 非法 `针(\d+)` 将 `排针17` 中的子串 `针17` 解析为「针 17 件」，折算为 5 计费件 → 5×5.5=**27.5**。**此结果确定错误。**

### 1.2 祖研院级规则（纸塑袋专用，本例不触发）

| 规则 | 类型 | 门禁 |
|------|------|------|
| 祖研排针10合1含包材 | FOLD | `排针@contains`，≤20 件，`额外包（纸塑袋）` |
| 祖研排针10合1免包材 | FOLD | `排针@contains`，≥21 件，`额外包（纸塑袋）` |

本例 **器械包 + 无纺布** → **规则未命中是正常、符合设计的**。  
不能把「客户纸塑袋账单上的 13.5」拿来要求本行必须等于 13.5。

### 1.3 界面「步骤 3」文案来源

步骤 3 不是规则名，而是 `PricingEngine` 写入 `notes` 的模板句（前端 `buildPricingFlowTimeline` 逐条展示为「计价说明」）：

```java
notes.add("包名含\"针" + needleQty + "\"，非针器械 " + nonNeedleCount
    + " 件 + 针折算 " + needleEquivalent + " 件（"
    + needleQty + "÷" + (int) foldRatio + "=" + needleEquivalent + "） = "
    + newEffectiveCount + " 件。");
```

对 `排针17/W6050`：`needleQty=17`（来自正则，非器械数列），`foldRatio=5` → 文案即用户看到的「针17…÷5」。

## 二、非法规则的技术定义

| 属性 | 内容 |
|------|------|
| **代号** | STD-09（文档编号）/ 全局针数量拆分 |
| **实现** | `Pattern.compile("针(\\d+)")` 对 `packName` 全串扫描 |
| **触发** | 任意子串匹配「针+数字」即执行，**不要求**命中 8 个合法小件关键词 |
| **折算** | `ceil(needleQty / foldRatio)`，默认 `foldRatio=5` |
| **与合法规则关系** | 在引擎中 **优先于** `findSmallItemSplit`（小件关键词 5 合 1），手册序位「2」在「3」之前 |

**合法通用小件规则**仅允许：包名以 **`exact_token` 命中 8 个关键词之一** 后，按 `threshold/foldRatio` 对 **账单器械数** 或包名分段小件件数折算——**禁止**裸扫描「针+数字」。

## 五、合法通用小件规则（删除 STD-09 后保留）

### 5.1 唯一合法关键词（8 个）

克氏针、银质针、内热针、车针、拔髓针、扩大针、根扩针、卷棉子。

（源：`DefaultPricingTemplate.java` L72；`phase-global-generic-fold-20260820.json` 对齐。）

### 5.2 合法折算路径（删除后仅剩）

1. 院级 `CustomerProductRule` FOLD/FIXED（含 `acceptedTypes` 等门禁）——**优先**；
2. 通用 `findSmallItemSplit`：包名 **`exact_token` 命中 8 词之一** → 按 `threshold=5` / `foldRatio=5` 对器械数或包名分段折算；
3. 通用 `genericSmallItemFoldRules`（特殊收费 Excel 8 项 5 合 1 含/免包材）；
4. 高温纸塑 ≥3 件且不命中小件词 → 按实件×5.5（`skipGlobalNeedleAndSmallFold`）——**与无纺布路径无关**。

**删除 STD-09 后，手册第五章折算次序应改为：仅「院级 FOLD → 小件关键词折算 → 纸塑≥3 不折算」，不再有「序位 2 针N」。**
