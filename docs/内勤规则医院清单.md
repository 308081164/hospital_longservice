## 三、典型院内勤规则详解

### 3.1 呼兰一院 `HULAN-RM` — 敷料包七折

- **类型：** 折扣叠加（`DISCOUNT_OVERLAY`）
- **摘要：** 标准敷料价 × 0.7；FIXED_PRICE 特色行跳过（`skipWhenFixedPrice`）
- **示例：** 棉签 STD-07 1.75 → 导出/账单 1.22；孔巾 2.8 → 1.96
- **来源：** `phase1-batch-a-extra.json`、`docs/呼兰第一人民医院4月账单折扣与校正价分析报告-20260915.md`
- **迁出动作：** 删除 `bill_detail` 策略；启用 clerk `isActive:true`

### 3.2 中医附一 `ZYY-D1` — 独立价表体系

- **类型：** 独立标准灭菌价（客服） + 11 列分科室导出（内勤）
- **摘要：** hybrid 模式下未命中特色规则走附一 Sheet2 价表；导出按科室多 Sheet、11 列
- **来源：** `phase-zyy-d1-fuyi.json`、`phase-export-fuyi-11col`
- **注意：** 价表属客服合同内容；仅导出布局/分表属内勤

### 3.3 太平人民 `TAIPING-RM` — 按把数阶梯

- **类型：** `PIECE_TIER_DISCOUNT`
- **摘要：** 1 把原价；2 把 75%；3 把且原价 16.5 → 8.91；4+ 把 75%
- **来源：** `phase5-batch-c.json`
- **状态：** clerk baseline 已激活，与 legacy `export_only` 等价

### 3.4 省二南岗挖勺 — 5.5 元参与七折

- **类型：** 挖勺 FIXED 5.5 = **客服规则**；整单七折 = **内勤规则**
- **摘要：** 计价层 5.5 元/件；内勤导出时再 × 0.7 → 3.85
- **来源：** `phase-user-20260722-er-hulan.json`
- **注意：** 勿将挖勺固定价迁入 clerk

### 3.5 固定单价 5.5 → 3 元（用户举例）

- 系统中类似模式为 **exportApply 固定价**（导出时覆盖），分布在市五、三精、呼兰中医等
- 规则类型：`FIXED_PRICE_EXPORT`
- 待 Phase D 从 manifest 批量抽取
