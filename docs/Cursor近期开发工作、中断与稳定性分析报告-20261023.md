### 6.5 根因判断

按可能性排序：

1. **Cursor 全局状态库 106GB + 磁盘仅剩 3%**：SQLite/WAL、聊天记录、索引写入都可能变慢或失败，是本地最异常的信号。
2. **远程工作区扩展宿主/搜索 provider 超时**：导致窗口卡死、索引不可用、Agent 工具调用失败。
3. **Cursor 服务端 `connectCode: 14`**：Agent 重试 4 次后停止，表现为“崩溃/中断”。
4. **仓库本身不是原因**：本仓库没有异常大文件进入 Git；106GB 是 Cursor 的全局状态库，不是项目仓库体积。
