## 门禁

市五院 **1 个完整账期** UAT：  
`手术室净额 + 调整表 + 各科室 Sheet + 外来器械 + 物流 = 原账单总额`

## 逐步脚本

### 1. 配置确认

- 客户组 **市五院结款合并组**：HRB-WY + HRB-WY-EM
- 费用调整关键词默认：`电钻`、`肖`、`啸`（BC-03 默认配置，可扩展）
- 外来器械包类别号：4–12 位字母数字（BC-04 默认规范）

### 2. 数据准备

1. 导入 MAT-01 账单（含手术室 Sheet）。
2. **花名册** Excel 导入医生→科室映射。
3. **外来器械** 页维护或 Job 关联导入。
4. **物流导入** 50 元/次。

### 3. 分配与导出

1. 对账 Job 审核通过 → `POST /allocate` 运行科室分配。
2. 核对 `allocation_result.balanced=true`。
3. 对账 UI：包名命中医生 → 侧边「建议科室」提示。
4. `POST /export-orchestrated` 下载 L3 多 Sheet 工作簿：
   - 分科室汇总 / 费用调整 / 科室分配明细 / 外来器械 / 价格汇总 / 源 Sheet

### 4. 勾稽

| 分项 | 来源 |
|------|------|
| 常规账单 | priceSummary.常规账单 |
| 费用调整 | 调整表合计 |
| 外来器械 | 外来器械 Sheet 合计 |
| 物流 | Job.logisticsFee |
| **合计** | = 导入账单总额 + 外来器械 + 物流 |

### 5. 二门诊

重复上述流程，结款函合并组导出一张总表。
