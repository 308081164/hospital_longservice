# 中医附一（ZYY-D1）内勤规则维护说明

## 定位

**`docs/source/附一收费标准.xlsx` 是中医附一的内勤规则权威来源**，与 `医院内勤规则-20260918.xlsx`（38 家）并列、独立维护。

同一份 Excel 经 `scripts/import_fuyi_standards.py` 生成两类产物：

| 产物 | 用途 |
|------|------|
| `clerk-rules/baseline/ZYY-D1.json` | 内勤规则 v2：导出布局、物流、结款附加、附表类型等 |
| `billing-rules/baseline/ZYY-D1.json` | **同源价表** → `PricingEngine` hybrid（对账计价必需，非第二套业务规则） |

## 变更流程

```bash
# 1. 更新 docs/source/附一收费标准.xlsx
python3 scripts/import_fuyi_standards.py
python3 scripts/refresh_baseline_index.py
python3 scripts/baseline_to_manifest.py --write
python3 scripts/baseline_to_manifest.py --check
```

## 能力实现状态（诚实口径）

| Excel 内容 | 内勤规则类型 | 系统能否完整实现 | 说明 |
|------------|-------------|-----------------|------|
| Sheet2 高温/低温阶梯价表 | 价表（→ billing hybrid） | **是** | `standardPricingOverride` + `capMode=fuyi` |
| Sheet2 特殊收费（腹腔镜/换药包/耳鼻喉 FOLD） | 价表补充 | **是** | `productRules` + supplement |
| Sheet2 敷料包固定价 | 价表补充 | **是** | FIXED_PRICE |
| 11 列 + 分科室账单 | `EXPORT_LAYOUT` | **是**（已接线） | `ClerkExportLayoutMerger` **覆盖** export_template 缺省布局 |
| 包材名标准化 | `EXPORT_LAYOUT.materialAliases` | **是**（已接线） | 导出前改写 `packageMaterial` |
| 物流 45 元/趟 | `LOGISTICS_FEE` | **是**（已接线） | 结款/物流预览经 `ClerkCompiledRulesResolver` 合并内勤策略 |
| 加急 125% | `URGENT` | **是**（已接线） | 结款函 `ClerkSettlementRequestEnricher` 自动填充费用行 |
| 手术一区洗涤费 | `SETTLEMENT_EXTRA` | **部分** | 结款函 + 分科室汇总附表按 `amountByMonth` 写行；**洗涤明细表无自动导入** |
| 分科室汇总 / 物流分摊 | `MONTHLY_SUPPLEMENT_REPORT` | **是**（已接线） | `FuyiSupplementWorkbookBuilder` 对齐确认包样表（科室/金额 + 物流四列） |
| 外来器械独立 Sheet | — | **否** | 需求登记 M12 未实现 |
| 洗涤明细 `中医附一2026.xx.xlsx` | — | **否** | 需独立导入通道或手工 `amountByMonth` |

**结论**：对账计价 + 11 列分科室账单 + 结款物流/加急/洗涤行 + 分科室汇总/物流分摊附表 **可交付**；洗涤明细自动导入、外来器械 Sheet 仍待实现。

### 关键接线（2026-09）

| 组件 | 作用 |
|------|------|
| `ClerkCompiledRulesResolver` | 计价规则 + 内勤结款策略合并（物流/加急/洗涤） |
| `ClerkSettlementRequestEnricher` | 结款函导出前自动填充 feeRows |
| `ClerkExportLayoutMerger` | 内勤 EXPORT_LAYOUT 覆盖账单布局 |
| `FuyiSupplementWorkbookBuilder` | 分科室汇总/物流分摊样表版式（列宽、标题、合计行） |
| `StandardDeptSummaryExportStrategy` | export-v2 `dept_summary` 走样表 builder |
| `LogisticsAllocationExportStrategy` | export-v2 `logistics_allocation` 走样表 builder |

## 补充规则

尚未写入 Excel 的生产条目在 `fuyi-rules/supplement.json`；迁移进 Excel 后从 supplement 删除并重新 import。
