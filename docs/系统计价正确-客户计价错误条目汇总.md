# 系统计价正确、客户计价错误条目汇总

> 来源：8.21new 批次严格对账（2026-08-22 执行）
> 口径：系统计价（铂康系统）正确，客户"做完账单"计价错误。共 4 条，涉及 2 家医院。

---

## 一、黑龙江省中医药大学附属第四医院（中医附四）

### 条目 1：持物钳罐-4件（卵2，剪1）/W6050

| 项 | 值 |
|---|---|
| 位置 | 账单 sheet「手术室」第 11 行 |
| 发货单号 | 1596552 |
| 类型 / 材料 | 额外包(无纺布) / 无纺布-60×60-50g |
| 包数 / 器械数 | 1 / 3 |
| 原始单价 | 22 |
| 客户账单价 | 22（未改，漏改） |
| **系统价** | **16.5** |

- **正确计价路径**：高温无纺布，每包件数 3 ≤ 3（`flatRateThreshold=3`）→ 收取最低价 `minCharge = 16.5`。
- **匹配规则**：高温无纺布计费（`minCharge: 16.5`，≤3 件按最低价）。
- **结论**：系统 16.5 正确；客户账单 22 错误，多收 5.5 元（客户账单编辑错误）。

### 条目 2：骨刮匙-1/Z7526

| 项 | 值 |
|---|---|
| 位置 | 账单 sheet「口腔（群力分院）」第 40 行 |
| 发货单号 | 1597316 |
| 类型 / 材料 | 额外包(纸塑袋) / 高温纸塑袋75*260（10cm 档） |
| 包数 / 器械数 | 2 / 4 |
| 原始单价 | 13.5 |
| 客户账单价 | 8（客户改错） |
| **系统价** | **13.5** |

- **正确计价路径**：高温纸塑袋 10cm，每包件数 = 器械数 4 ÷ 包数 2 = 2 件；2 件 < 3 → 件费 5.5 × 2 + 袋费 2.5 = 13.5。
- **匹配规则**：高温纸塑袋 10cm 计费（件数 < 3：`5.5 × 件数 + 袋费`；10cm 袋费 2.5）。
- **结论**：系统 13.5 正确；客户账单 8 错误（客户误按每包 1 件计费）。

## 二、黑龙江菁华上德生殖妇产医院（菁华上德）

### 条目 3：子痫包-3件/Z1526

| 项 | 值 |
|---|---|
| 位置 | 账单 sheet「产科病房」第 15 行（做完账单为第 14 行） |
| 发货单号 | 1609054 |
| 类型 / 材料 | 额外包(纸塑袋) / 高温纸塑袋150*260（15cm 档） |
| 包数 / 器械数 | 1 / 3 |
| 原始单价 | 22 |
| 客户账单价 | 22（未改，漏改） |
| **系统价** | **16.5** |

- **正确计价路径**：高温纸塑袋 15cm，每包件数 3 ≥ 3 → 免收袋费，件费 5.5 × 3 = 16.5。
- **匹配规则**：高温纸塑袋 15cm 计费（件数 ≥ 3 时免袋费）；同时该院另有固定价规则「上德子痫包16.5」（price 16.5），两路径结果一致均为 16.5。
- **结论**：系统 16.5 正确；客户账单 22 错误，多收一份 15cm 袋费 5.5 元。

### 条目 4：穿刺针-1（带芯）/Z7526

| 项 | 值 |
|---|---|
| 位置 | 账单 sheet「妇科」第 19 行（单号 1615561）、sheet「手术室」第 376 行（单号 1614947） |
| 发货单号 | 1614947、1615561 |
| 类型 / 材料 | 额外包(纸塑袋) / 高温纸塑袋75*260（10cm 档） |
| 包数 / 器械数 | 1 / 2 |
| 原始单价 | 13.5 |
| 客户账单价 | 13.5（未改，漏改） |
| **系统价** | **8.0** |

- **正确计价路径**：高温纸塑袋 10cm，穿刺针属小件（`needle` 关键词），器械数 2 ≤ 5（`threshold=5`）→ 按 1 件计费：件费 5.5 × 1 + 袋费 2.5 = 8.0。
- **匹配规则**：高温纸塑袋 10cm 计费 + 小件折算（`needle` 规则，≤5 件按 1 件计费）。
- **结论**：系统 8.0 正确；客户账单 13.5 错误（客户按 2 件计费、未按小件折算）。

## 附：说明

- 以上 4 条的"系统价"均由铂康系统按通用/客户规则自动算出，且与客户"原始账单"价格一致或符合客户自建规则，判定为系统正确。
- "客户账单价"来自客户"做完账单"文件，存在漏改（条目 1、3、4）或改错（条目 2）的情况。
