# 账单导出规则说明（客户审阅版）

> **配套样例**：请同时打开本文件夹内 `样例-按医院/`（逐院核对）与 `样例-按导出类型/`（按处理方式对照）。详见 `00-阅读说明.md`。


> **文档说明**  
> 本文说明系统在对账完成后，**导出 Excel 时**对表格内容、列、工作表（Sheet）做了哪些处理。  
> 便于与您提供的样表、手工处理后的 Excel 对照审阅。  
> **本文不涉及**系统内部如何计算校正价、如何匹配包名规则（属计费环节，另册说明）。  
> **版本日期**：2026 年 9 月

---

## 一、通用说明（适用于多数医院）

### 1.1 系统可导出的文件

| 文件类型 | 用途 |
|----------|------|
| **已改账单** | 按包/行列出校正后的发货明细，供客户核对 |
| **结款函** | 汇总灭菌费、物流费等，供财务结款 |

除下文明示的医院外，其余医院**仅提供以上两种**导出文件。

### 1.2 标准「已改账单」包含的列（共 8 列）

| 列名（系统表头） | 常见别名（若样表用别名，系统会对应识别） |
|------------------|----------------------------------------|
| 发货日期 | 灭菌日期 |
| 发货单号 | 灭菌锅次 |
| 类型 | |
| 包类别号 | 病人 ID |
| 包名 | 器械名称 |
| 包数 | |
| 单价 | |
| 总价 | |

**行**：每一行对应一条（或一组聚合后的）发货/灭菌记录，按对账结果填入包名、件数、单价、总价等。

### 1.3 标准「结款函」

- 按结款函版式输出费用汇总（如灭菌费、物流费等分项及合计）。
- 无独立折扣行的医院：折扣已在账单金额中体现，结款函不再单独列折扣行。

### 1.4 默认分表方式

- **多数医院**：所有明细在**同一个工作表**中输出。
- **数据量特别大时**（超过约一千行）：系统自动改为**一张合计表**，避免文件过大无法打开（与「按科室分表」不同，见下文）。

**附表含义简述**

- **分科室汇总表**：按科室汇总包数、把数、金额等，不展开到每一包明细。  
- **价格汇总表**：按价格档位或规则汇总金额。  
- **把数/器械核对表**：列出科室、包名、把数、包数等，便于核对器械件数。  
- **物流分摊表**：展示物流费用在各科室之间的分摊结果。  
- **总计表**：全院或合并口径的合计汇总。

## 五、审阅时建议对照方式

1. **列**：数一数导出账单从左到右有哪些列，与上表或第三节是否一致。  
2. **行**：国药三院等需确认是「逐行明细」还是「按包类别号合并后的行」。  
3. **Sheet**：打开 Excel 底部标签，确认是「一个表」还是「每科室一个表」。  
4. **金额**：太平、呼兰一院、中医三院等需用样表核对**导出文件中的单价/总价**，不要仅看系统对账界面单行数字。  
5. **结款函**：工程大学、九院等确认是否有**单独的折扣行**；市五院确认主院与二门诊是否需**合并一份结款函**。
