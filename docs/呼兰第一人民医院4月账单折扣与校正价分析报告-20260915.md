**客户代码：** `HULAN-RM`（哈尔滨市呼兰区第一人民医院）  
**计价模式：** `hybrid`（特色规则优先，未命中走标准灭菌阶梯）

## 一、执行摘要

| 问题 | 根因（一句话） |
|------|----------------|
| 为什么部分行打折、部分不打折？ | 呼兰配置了 **账单明细 7 折**（`呼兰7折`，rate=0.7），但 **命中 FIXED_PRICE 特色规则的行会跳过折扣**（`skipDiscount:true` + `skipWhenFixedPrice:true`）；未命中特色的行走标准阶梯后再乘 0.7。 |
| 为什么纱布/棉球出现「客户校正价」？ | 包名含 **「纱布」或「棉球」** 子串即可命中 `PDF纱布棉球大20x20x15`（28 元/包），引擎写入 `pricingPath=fixed`，对账 UI 将其归类为 **「客户校正价」**——并非旧版「校正价」前缀规则名。 |
| 账单单价与引擎是否一致？ | **棉签/孔巾等标准敷料行**：账单价 ≈ STD-07 标准价 × 0.7，与引擎一致；**纱布/棉球行**：账单价 1.75～2.5 元，引擎建议 **28 元**（误命中 PDF 大包固定价），严重不一致。 |

**建议优先修正：** `PDF纱布棉球大20x20x15` 的关键词语义（当前 OR 匹配过宽），与客户 PDF 价单「20×20×15 大规格纱布棉球整包 28 元」对齐。

## 二、项目中「折扣」规则类型全览

系统存在 **6 类与「打折/减价」相关的机制**，分属不同生效阶段，不可混为一谈。

### 2.1 账单明细折扣（最常见，影响对账「规则单价」）

| 属性 | 说明 |
|------|------|
| **存储** | `customer_billing_policy`（`policyType=DISCOUNT`）或 legacy 表 `customer_discount` |
| **编译** | `PricingRuleCompiler.applyBillingPolicies()` → `billingPolicies[]`；ANY 温区 `bill_detail` 策略同步写入 `customerOverrides.discountRate` |
| **生效位置** | `PricingEngine.processRow()` 末尾 → `BillingPolicyApplier.applyBillDetailDiscounts()` |
| **计算** | `折后单价 = round(基础规则单价 × rate)`；`pricingRule` 追加后缀如 `+ 哈尔滨市呼兰区第一人民医院 折扣` |
| **阶段别名** | `applyStage` 为 `bill_detail` 或 `after_base` 均视为账单明细折扣（`BillingPolicyApplier.stageMatchesSingle`） |
| **跳过条件** | ① 商品规则 `skipDiscount:true` → `skipHospitalDiscount`；② 命中 FIXED_PRICE 且策略 `skipWhenFixedPrice:true`（默认 true） |

**呼兰配置（种子 `phase-hulan-heu-hit-20260722.json`，生产落 DB）：**

```json
{
  "name": "呼兰7折",
  "rate": 0.7,
  "applyStage": "after_base",
  "skipWhenFixedPrice": true
}
```

### 2.2 结款函灭菌费折扣（`settlement_only`）

| 属性 | 说明 |
|------|------|
| **生效阶段** | 仅结款函模板填表时 |
| **位置** | `SettlementTemplateFiller.buildFeeRows()` → `BillingPolicyApplier.applySettlementDiscount()` |
| **影响** | **不改变** Excel 对账行的 `expectedUnitPrice` |
| **示例** | 哈尔滨工程大学「结款函灭菌 9 折」 |

### 2.3 导出阶段折扣（`export_only`）

| 属性 | 说明 |
|------|------|
| **生效阶段** | 导出「已改账单」Excel 时 |
| **位置** | `ExportStageDiscountApplier.apply()` |
| **影响** | 改写导出文件中的单价/总价；对账 Job 内已计价行不变 |
| **特殊参数** | `skipWhenAlreadyDiscounted`、`fixedPriceOverrides`（原价→折后价映射） |

### 2.4 规则级「不计客户折扣」`skipDiscount`

| 规则类型 | 编译字段 | 效果 |
|----------|----------|------|
| `FIXED_PRICE` | `skipHospitalDiscount` | 命中后不再叠客户 bill_detail 折扣 |
| `PRICE_PER_INSTRUMENT` | 同上 | 同上 |
| `MULTIPLIER` / `EXTRA_FEE` | 同上 | 同上 |
| `FOLD` | **当前未映射** `skipDiscount` | 默认仍可享受客户折扣（呼兰棉花针 FOLD 即如此） |

**惯例：** baseline 中所有 `FIXED_PRICE` 必须 `skipPackaging:true` + `skipDiscount:true`（`BaselineRuleSyncServiceImpl` 强制）。

### 2.5 客户商品倍率 `MULTIPLIER`（非折扣，但改变单价）

命中后 `基础价 × multiplier`；可通过 `skipDiscount` 控制是否再打折。与呼兰 4 月账单无直接关系。

### 2.6 加急物流折扣率 `urgentLogisticsDiscountRate`

结款函加急物流费 × 折扣率（默认 0.9），由 `UrgentFeeCalculator` 处理，不影响单行器械灭菌单价。

## 三、计价流水线（与折扣的关系）

```
Excel 行导入
    ↓
PricingRuleCompiler（合并 baseline 商品规则 + DB 折扣策略）
    ↓
PricingEngine.processRow()
    ├─ 1. 特色 FIXED / FOLD / MULTIPLIER …（hybrid 优先）
    ├─ 2. 未命中 → 标准灭菌（高温纸塑 / 无纺布 / 敷料 STD-06/07）
    ├─ 3. 包装费 / 小件折算 / 针数规则
    └─ 4. BillingPolicyApplier.applyBillDetailDiscounts()
           ├─ skipHospitalDiscount? → 跳过
           ├─ hitFixedPrice && skipWhenFixedPrice? → 跳过
           └─ 否则 basePrice × 0.7
    ↓
写入 reconciliation_row：pricingRule / expectedUnitPrice / billingNotes.effectivePricingPath
```

## 四、「客户校正价」在 UI 中的含义（易误解点）

对账页徽章 **「客户校正价」** 来自 `frontend/src/utils/reconciliationPricingPath.ts`，判定条件为：

1. `billingNotes.effectivePricingPath === 'fixed'`（引擎命中 `FIXED_PRICE` 或产品公开价），**或**
2. 兼容旧数据：`pricingRule.startsWith('校正价')`

因此：

- **显示「客户校正价」≠ 规则名含「校正价」**；呼兰行展示的是规则真名 `PDF纱布棉球大20x20x15`。
- 任何命中 `FIXED_PRICE` 的行都会显示该徽章，并因 `skipDiscount:true` **不再享受呼兰 7 折**。

## 七、引擎试算复现（本地 manifest + 模拟呼兰 7 折）

在 `HULAN-RM` 规则上注入与生产一致的 `呼兰7折` 策略后试算：

| 包名 | 类型 | 账单单价 | 引擎 pricingRule | 建议单价 | pricingPath | 是否打折 |
|------|------|----------|----------------|----------|-------------|----------|
| 纱布/Z1526 | 敷料包(纸塑袋) | 1.75 | `PDF纱布棉球大20x20x15` | **28.00** | **fixed** | 否 |
| 棉球/Z1020 | 敷料包(纸塑袋) | 2.50 | `PDF纱布棉球大20x20x15` | **28.00** | **fixed** | 否 |
| 棉签/Z1026 | 敷料包(纸塑袋) | 1.75 | `敷料包(纸塑袋)——10cm + …折扣` | **1.75** | standard | **是**（2.5×0.7） |
| 孔巾/Z2032 | 敷料包(纸塑袋) | 2.80 | `敷料包(纸塑袋)——20cm + …折扣` | **2.80** | standard | **是**（4.0×0.7） |
| 止血钳-1/Z1029 | 额外包(纸塑袋) | 5.60 | `高温纸塑袋15cm计费 + …折扣` | 19.25* | standard | 是 |

\* 止血钳示例按 5 件计；与账单 5.6 元单行需结合件数核对，此处仅说明折扣后缀会出现。

**结论：**

- **「部分打折」** = 标准路径行 ×0.7；**「部分不打折」** = 命中 `PDF纱布棉球…` 等 `skipDiscount:true` 的 FIXED 行。
- 棉签/孔巾账单价与 `STD-07 × 0.7` 吻合，说明 **7 折策略对标准敷料行工作正常**。
- 纱布/棉球账单价（1.75～2.5）与引擎 28 元 **严重偏离**，属于 **规则误命中**，不是折扣开关问题。

## 八、根因：`PDF纱布棉球大20x20x15` 关键词过宽

### 8.1 规则设计意图（价单语义）

规则名含 **「大 20×20×15」**，应对应客户 PDF 中 **大规格纱布棉球整包 28 元**，而非所有含「纱布」或「棉球」字样的纸塑小敷料。

### 8.2 实际匹配逻辑（源码）

`BillingConditionEvaluator.matchesKeywordsByMode()` 对规则关键词数组采用 **「任一命中即通过」（OR）**：

- 包名 `纱布/Z1526` → 命中关键词 `纱布` → **整条规则生效 → 28 元**
- 包名 `棉球/Z1020` → 命中关键词 `棉球` → **28 元**
- 包名 `眼科纱布/Z1026` → 命中 `纱布` → **28 元**
- 包名 `棉签/Z1026` → **不**含子串 `纱布` 或 `棉球` → 不命中 → 走 STD-07

`matchMode: "first"` 表示规则之间的优先级，**不**表示关键词 AND。

### 8.3 与 UI「客户校正价」的因果关系

```
包名含「纱布」或「棉球」
    → 命中 FIXED_PRICE（priority 15）
    → pricingPath = fixed，pricingRule = PDF纱布棉球大20x20x15
    → skipDiscount:true → 不乘 0.7
    → 对账 UI：徽章「客户校正价」+ 规则名单价 28 元
```

## 十、修正建议（按优先级）

### P0 — 修正 `PDF纱布棉球大20x20x15` 匹配范围

1. **与客户 PDF 核对**：28 元是否仅适用于「20×20×15 大规格」整包，而非 Z1526/Z1020 等小纸塑敷料。
2. **baseline 调整方向（择一）：**
   - 关键词改为须 **同时** 包含尺寸串（如 `20cm*20cm*15cm`）及「纱布」「棉球」——需引擎支持 AND 或合并为单一关键词 `纱布棉球` + 尺寸 material 条件；
   - 或 **删除** 该规则中对单字 `纱布`/`棉球` 的宽泛匹配，改为 `bagSizeEquals` / `materials` 约束；
   - 若小敷料有独立 PDF 价，应 **另建 FIXED** 规则（如 1.75 元）并设更高 priority。
3. 变更后走规范闸门：G1 manifest、G3 `rules verify --all`、路径 A 呼兰账期 strict-v8 复跑。

### P1 — 文档与 UI 澄清

- 在对账说明中注明：**「客户校正价」= 命中客户 FIXED_PRICE**，与历史「校正价」前缀脱钩。
- 呼兰院可标注：**标准灭菌价 ×0.7；PDF 固定价清单内项目不再打折**。

### P2 — 可选引擎增强

- 支持规则级 `keywordMatchMode: all`（关键词 AND），避免「纱布」「棉球」两条 OR 误伤。
- `FOLD` 规则编译时映射 `skipDiscount`，与 FIXED 行为一致。
