# 测试用例目录

本目录由 `scripts/reorganize_test_cases.py` 自动生成，用于按医院组织账单测试数据。

## 目录结构

```
测试用例/
  {医院名称}/
    原始表格/          # 来自 铂康/AI账单（原始未处理的）/（系统导入格式）
    处理后表格/        # 来自 铂康/2026年账单(正确的)/（人工处理导出格式）
```

若某医院缺少某一类文件，对应子目录命名为 `【缺】原始表格` 或 `【缺】处理后表格`。
