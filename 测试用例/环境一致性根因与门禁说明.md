# 环境一致性根因与只读门禁说明

> 更新：2026-07-29 · 策略：**生产只读门禁**（不批量 import 测试 Job）

## 背景

本地 Docker 与生产 8853 在账单核对（S1→S4→S8）结果上长期存在差异。2026-07-29 完成 prod 只读审计后确认：**主因是数据生命周期分离 + 验收口径混用**，而非本轮 deploy 功能回归。

| 项 | 本地 Docker | 生产 8853 |
|----|-------------|-----------|
| Job 来源 | `batch_june_system_test.py` 批量 S4 import | 运营/UI 长期导入 |
| Job 映射 | `job_baseline_stable.json`（607–704） | `job_baseline_prod.json`（约 20/37 院） |
| 完整 wave6 对标 | ✅ 37 院 | ❌ 不可比（缺 18 院 Job） |
| 写库 | 允许 S4 import | **禁止** import / S4 重导 |

---

## 五类根因（RC1–RC5）

### RC1 数据生命周期分离（高）

- 本地通过 stable Job 批量建库；生产为独立运营库，Job ID、账期、院覆盖均不同。
- 例：附一 stable 607 → prod 208；哈工大 stable 691 → prod 77。
- **杜绝**：双轨 Job map（`stable` vs `prod`）；prod 禁止用 stable ID 跑 S8。

### RC2 验收口径混用（高）

- 旧版 prod 报告硬对标 local wave6（bill 34/4/0）→ 18 院 skip 被误标 **93 条 P0**。
- **杜绝**：`billing_reconciliation_report.py --profile prod` 使用 `coverage_gap` 分级，不与 wave6 硬对标。

### RC3 CI 门禁不足（中 → 已增强）

- 部署后仅 `run-prod-verify.sh smoke`，无 calibrate / coverage / **productRules** 检查。
- **杜绝**：`deploy.yml` Post-deploy parity gate = smoke + **`rules compare --fail-on-drift`** + calibrate + coverage warn。
- backend 启动 **`BillingRulesManifestReconciler`** 按 manifest 全量 upsert，避免 seed marker 跳过后规则长期偏少（例：附一 ZYY-D1 生产仅 6 条）。

### RC4 工具链缺陷（中，已修复）

- 中文 `hospital_name` 未 URL 编码；S4 audit 忽略 `--job-map`；S8 export 相对路径崩溃。
- **杜绝**：合入 main + 单测/冒烟覆盖。

### RC5 部署时序（低）

- 部署窗口内跑 export 导致「非 xlsx」误报；部署后 smoke 已恢复。
- **杜绝**：`run_prod_billing_audit.sh` 等待 health + smoke PASS 后再 S8。

## 只读门禁验收口径（prod）

| 检查项 | 通过条件 | CI 是否 fail |
|--------|----------|--------------|
| preflight | smoke OK | ✅ fail |
| **rules parity** | `rules compare --all` missing/extra/changed=0 | ✅ fail |
| coverage | 记录 found/missing | ❌ warn only |
| 有 Job 院 S8 | export-v2 成功（非 xlsx） | ✅ fail |
| 有 Job 院 S4 | missed=0 | ✅ fail |
| 无 Job 院 | `coverage_gap` → P3 | ❌ |
| local vs prod | INFO，不升 P0 | ❌ |

### 偏差分级

| 级别 | 含义 |
|------|------|
| **P0** | 有 Job 且 export 失败 / S4 漏检 |
| **P1** | 有 Job 且 S8 bill fail（已知材料院） |
| **P2** | fail_extra、登记口径差 |
| **P3** | coverage_gap（缺 Job）、环境项 |
| **INFO** | local vs prod 状态差异（预期可不同） |

## 双轨 Job 基线

| 文件 | 环境 | 更新方式 |

## 操作命令

```bash
bash scripts/run_prod_billing_audit.sh --skip-deploy   # 已部署后

```

```bash
python3 scripts/calibrate_prod_job_map.py --api http://39.102.213.51:8853 --mode direct
```

```bash
bash scripts/run_prod_parity_gate.sh
```
