# 待匹配测试用例

本目录存放**无法自动匹配到具体医院**的账单文件，作为 `测试用例/{医院名称}/` 的补充归档。

## 目录结构

```
待匹配/
  原始表格/      # 系统导入格式的原始账单（未处理）
  处理后表格/    # 人工处理/导出格式的账单
```

## 数据来源

| 子目录 | 原铂康路径 | 说明 |
|--------|-----------|------|
| 原始表格 | `铂康/AI账单（原始未处理的）/` | AI 导入原始格式 |
| 原始表格 | `铂康/账单原始数据-4(1)/账单原始数据-4/` | 补充原始数据 |
| 处理后表格 | `铂康/2026年账单(正确的)/` | 2026 年正确账单（递归） |
| 处理后表格 | `铂康/已做完账单(1)/` | 已完成账单（递归） |

> 上述铂康源目录在整理完成后已删除；文件已复制至本目录或各医院子目录。

## 为何在此

这些文件在自动匹配时无法唯一对应 `铂康/参考文件（按照医院）/` 中的任一医院，常见原因包括：

- 文件名/路径缺少医院标识或别名
- 多家医院共用汇总文件（如省医院外来器械汇总）
- 医院尚未纳入参考目录（如部分社区、诊所）
