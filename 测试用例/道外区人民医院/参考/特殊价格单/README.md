### 外来器械 seed 说明（重要）

- 系统 **暂无 M12 外来器械计价能力**；PDF 条款 **只记录**，6 月样例账单 **无** 对应行。
- 规则名 `PDF外来器械钉盒37.5` / `PDF外来器械骨电钻12.5` 的关键词必须为全短语 **`外来器械（钉盒）`**、**`外来器械（骨电钻）`**，**不得**使用裸 `钉盒` / `骨电钻`（易误命中非外来器械包名）。
- 即使 seed 已写入 DB，在引擎支持前 **不保证** 与合同价自动对齐。

### pathOverride（未写入 seed）

铂康与 `7.17` 要求：**无低温**、高温 **3 元/件**。当前 **billing-seeds 无 `pathOverride`**，仅测试 golden 与文档；见梳理文档第四节。
