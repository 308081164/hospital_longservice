## 图例（状态列）

| 状态 | 含义 |
|------|------|
| **已实现** | 规则/策略/override 已落库，且 6 月对账（或账单样例）已验证 |
| **备案** | 已写 `customer_product_rule` 或文档价，但 **M12 外来器械** 等引擎不完整，包名不匹配时不应误计价 |
| **仅记录** | 合同/PDF/铂康口头有描述，**未**落库、或当前账单无对应包名、或属 M8 导出折扣等非 M3 范围 |
| **不适用** | 该院计价不依赖该 PDF 条款 |
| **缺引擎** | 需求明确但系统能力缺失（如 pathOverride、minCharge、M12 分包重量） |

**缩写：** **备案** = M12 外来器械类固定价 + 全短语关键词；**仅记录** = 无稳定包名或未支持能力。
