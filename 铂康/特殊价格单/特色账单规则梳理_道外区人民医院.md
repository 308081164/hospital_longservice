## 三、已识别但系统暂不支持（或仅合同/PDF 记录）

1. **外来器械体系**（分包重量 7kg、植入物生物监测加收、多品类固定价）— seed 仅备案，**不保证账单匹配**；关键词必须用 **`外来器械（钉盒）`**、**`外来器械（骨电钻）`** 全短语。
2. **9 元起包**（附表一-1 minCharge）。
3. **敷料/外来器械「超出重量分包」** 计价。
4. **敷料大/中/小（19 / 22.5 / 26.5）** — PDF 有，**样例账单未出现**；样例只验 **6.5** 的 `敷料`/`敷料包`。
5. **生物监测/次**（PDF 快速生物监测试剂）。
6. **被服洗涤**（PDF §7）。
7. **单把表低温过氧化氢** 等（道外业务声明无低温，但 PDF 仍有条目）。
8. **pathOverride**（无低温 + 全单高温 3 元/件）— 需求明确，**DB seed 未写入**。
9. **辅料包价格明细** — 铂康 `特色账单规则.txt` 标注「缺少辅料包价格明细」（OQ-02 同类）。

### 钉盒 / 骨电钻关键词修正说明

- **错误**：`keywords: ["钉盒"]` / `["骨电钻"]` 会命中普通包名中的子串，且与「外来器械」业务语义不符。
- **正确**：`["外来器械（钉盒）"]`、`["外来器械（骨电钻）"]`（与 PDF/OCR 表述一致；账单若仅写「钉盒」需业务确认是否外来器械行）。
- **代码**：`phase-s7-bokang-pdf-ocr-20260723.json` 已改；已应用 S7 的库用 `phase-s7-daowai-wailai-keywords-20260723.json`（marker `billing_seed_s7_daowai_wailai_keywords_20260723_v1`）做 `setKeywords` 补丁。

### pathOverride 交叉核对（Deliverable C）

- **结论**：在 `backend/src/main/resources/billing-seeds/` **全部 JSON** 中 **未发现** `pathOverride`、`disableLowTemp`、`forceHighTempUnitPrice` 字段。
- **期望**（`7.17` + 铂康 §9 + `hospital-billing-golden-rows.json`）：DAOWAI-RM 应配置 `disableLowTemp: true` + `forceHighTempUnitPrice: 3.0`。
- **建议**：新增 `customerUpdates` 增量 seed（或 UI 配置）写入 `billingProfile`，并在 4–5 月账单回归中验证。
