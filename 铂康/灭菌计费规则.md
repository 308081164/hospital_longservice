# 灭菌计费规则

> **计费通则** — 单包件数 = 器械数 ÷ 包数（若器械数 = 0，则默认为 1 件）；包数至少为 1。
> 以下所有计费均基于**单包件数**计算。

---

## 高温 / 低温判定

| 类型包含关键词     | 判定结果 |
| :----------------- | :------- |
| "低温"、"ETO"      | **低温** |
| 其余情况（含 ZSD） | **高温** |

> ZSD 走高温规则，不再识别为低温。

---

## 件数预处理（仅低温生效，在单包件数计算之后执行）

### 低温 — 盒不收费

当**类型**包含"低温"或"ETO"，且**包名**包含"盒"，且**器械数 ≠ 1** 时，器械数减 1（盒不收费）。

> 示例：器械数 3，减 1 后按 2 件计费。

### 低温 — 按"件"前数字取器械数

当**类型**包含"低温"或"ETO"，且**包名**不含"盒"时，尝试从包名中提取汉字"件"前面的数字。若提取结果 ≠ 当前单包件数，则以提取数字为准。

> 示例：包名"腹腔镜器械13件"，提取 13，若单包件数不是 13 则替换。

> 注意：提取在「器械数 ÷ 包数」之后执行，确保提取的"件"数与单包件数做比较。

### 小物件折算（高低温通用）

当**包名**包含以下任一关键词，且单包件数 ≥ 触发阈值（默认 5 件）时，按折算比例重算件数（默认每 5 件折算为 1 件，向上取整）。

**小件识别关键词（共 13 个）：**

```
针、小件、探针、穿刺针、缝合针、车针、拔髓针、成型片、根管针、根管锉、洁牙机尖、球钻、挖勺
```

> 匹配方式：包名中**包含**任一关键词即触发，非完全匹配。
>
> 示例：包名"车针包-15件"，命中"车针"，单包 15 件 ≥ 5，折算后按 ceil(15÷5) = 3 件计费。

---

## 高温规则

> 类型中不含"低温"、"ETO"时，走高温规则（含 ZSD）。
> 高温环境**不执行**"盒 −1"和"件提取"预处理。

### 无纺布

小于 3 件收 **16.5 元**，大于 3 件按 **5.5 元/件** 计费。

| 件数 | 单价（元） |
| :--- | :--------- |
| 1    | 16.5       |
| 2    | 16.5       |
| 3    | 16.5       |
| 4    | 22.0       |
| 5    | 27.5       |

> 注：3 件时的 16.5 元等同于旧规则 3×5.5，结果不变。

### 纸塑袋

**计费规则：** 5.5 元 × 件数 + 纸塑袋费用；
若件数 ≥ 3 且件数总价超过 16.5 元，按 5.5 元 × 件数计费，不再加收袋费。

> **尺寸上限：** 纸塑袋尺寸大于 25cm 时，均按 25cm 标准收费（即最大袋费为 10.5 元）。

**袋型费用：**

| 袋型                | 尺寸 | 费用（元） |
| :------------------ | :--- | :--------- |
| 纸塑袋 25cm（特大） | 25cm | 10.5       |
| 纸塑袋 20cm（大）   | 20cm | 7.5        |
| 纸塑袋 15cm（中）   | 15cm | 5.5        |
| 纸塑袋 10cm（小）   | 10cm | 2.5        |

### 纸塑袋 — "双"规则

当包名中含**"双"**字时，在原袋费基础上额外加收一个纸塑袋费用。尺寸从"双"后提取**前两位数字**（如"双15"→15cm；特殊映射：**75→10cm**）。

> 若"双"后紧跟汉字（如"双层"），则不追加额外袋费。

额外袋费叠加后，封顶规则与上方正常高温纸塑袋一致：件数 ≥ 3 且件数总价超过 16.5 元时，免收所有袋费（含双袋费），按 5.5 元 × 件数计费；其余情况封顶 16.5 元。

### 敷料包（无纺布包）

当类型为**敷料包（无纺布包）**时，按无纺布规格定价：

| 无纺布规格 | 单价（元） |
| :--------- | :--------- |
| < 90       | 25         |
| = 90       | 30         |
| 1.2 ~ 1.5  | 35         |

### 敷料包（纸塑袋）+ 棉球

当类型为**敷料包（纸塑袋）**且包名中含有**"棉球"**时：

| 纸塑袋规格 | 单价（元） |
| :--------- | :--------- |
| 20cm       | 4          |
| 15cm       | 2.5        |

---

## 低温规则

> 类型中包含"低温"或"ETO"时走低温规则（ZSD 不走低温）。

件数 = 器械数 ÷ 包数（若器械数 = 0，则默认为 1 件），件数再经上方「件数预处理」规则调整。

### 单件（件数 = 1）

| 包装材料 / 尺寸         | 单价（元） |
| :---------------------- | :--------- |
| 低温灭菌 30cm（纸塑袋） | 35         |
| 低温灭菌 25cm（纸塑袋） | 30         |
| 低温灭菌 20cm（纸塑袋） | 28         |
| 低温灭菌 15cm（纸塑袋） | 25         |
| 低温灭菌 10cm（纸塑袋） | 22         |
| 无纺布（不限尺寸）      | 35         |

### 纸塑袋 — "双"规则（低温单件）

当包名中含**"双"**字且件数 = 1 时，在原袋费基础上额外加收一个纸塑袋费用（尺寸提取规则同上：前两位数字，75→10cm）。若"双"后紧跟汉字则不加收。

> 示例：低温单件纸塑袋 15cm + 双袋 20cm = 25 + 28 = **53 元**。

### 多件（件数 > 1）

不区分包装材料，基准单价为 **22 元/件**。

**5 件及以内：** 按 22 元 × 件数计费，封顶 88 元。

> 示例：4 件 = 4 × 22 = 88，受封顶限制即为 88 元。

**超过 5 件：** 按阶梯套价拆分，优先使用大阶梯（降序贪婪算法），剩余件数按 22 元/件。

**阶梯套价：**

| 阶梯名称              | 价格（元） | 包含件数 |
| :-------------------- | :--------- | :------- |
| 低温灭菌（套）— 20 件 | 300        | 20       |
| 低温灭菌（套）— 10 件 | 165        | 10       |
| 低温灭菌（套）—  5 件 | 88         | 5        |

> **阶梯拆分算法：** 从大到小贪心匹配。如 13 件 = 10 件套（165） + 3 × 22 = 231 元，而非 5+5+3 件。

**封顶规则（按所在区间）：**

| 件数区间 | 封顶价格（元） |
| :------- | :------------- |
| ≤ 5 件   | 88             |
| ≤ 10 件  | 165            |
| ≤ 20 件  | 300            |

### 常见单价速查

| 件数 | 总价（元） | 拆分方式       |
| :--- | :--------- | :------------- |
| 6    | 110        | 88 + 1 × 22    |
| 7    | 132        | 88 + 2 × 22    |
| 8    | 154        | 88 + 3 × 22    |
| 12   | 209        | 165 + 2 × 22   |
| 13   | 231        | 165 + 3 × 22   |
| 15   | 253        | 165 + 88       |
| 21   | 322        | 300 + 1 × 22   |
| 25   | 388        | 300 + 88       |
| 30   | 465        | 300 + 165      |
| 35   | 553        | 300 + 165 + 88 |

### 一般计算公式

当不命中阶梯套价（剩余件数不足任一阶梯）时：

> **总价 = 下一档套装单价 + 超出件数 × 22**

## 包装耗材收费

在以上灭菌计费完成后，系统会检测是否需加收包装耗材费：

- **医院自行打包：** 若命中自行打包关键词，仅收灭菌费，不收包装费。
- **标准包装收费：** 根据包装材料中的规格尺寸匹配对应的包装耗材价格，按"每包收费"或"按件收费"模式叠加。

> 包装收费在灭菌费计算完成后叠加，最终总价 = 灭菌计费 + 包装耗材费。
