# 冠唐云仓库 · 货品信息批量导入 · 开发计划说明

> 面向业务方 | 编制日期：2026年7月10日

---

## 一、项目背景

企业在启用「冠唐云仓库」时，通常已有大量货品资料和历史库存，若逐条手工录入，耗时长、易出错，也难以在多仓库场景下快速完成期初建账。

本次开发的核心方向是：**支持通过 Excel 一次性批量导入货品信息，并可选择同时导入各仓库的初始库存与初始库存金额，缩短系统上线与日常维护时间。**

---

## 二、本次开发目标

1. 支持 **货品基本信息批量导入**（名称、编码、类型、规格等）
2. 支持 **初始库存数量** 与 **初始库存金额** 一并导入，自动生成期初入库记录
3. 支持 **多仓库分仓导入**：各仓库数据可分别整理、分别导入
4. 提供 **标准 Excel 模板下载** 与清晰的导入结果反馈
5. 完善 **导入前校验与错误提示**，减少反复试错

**预计完成时间：2026年7月15日 晚上 12:00 前**

---

## 三、功能清单

| 序号 | 功能模块 | 业务说明 |
|------|----------|----------|
| 1 | **标准模板下载** | 在货品管理页面提供「导入 → 导入货品信息 → 模板下载」，客户按统一格式整理数据 |
| 2 | **货品基本信息导入** | 批量写入货品名称、编码（可不填由系统自动编码）、类型、规格、单位等信息 |
| 3 | **初始库存导入** | 可在模板中填写「当前库存数量」，导入后写入对应仓库库存 |
| 4 | **初始库存金额导入** | 可在模板中填写「当前库存金额」（货品总价），系统自动计算平均成本 |
| 5 | **期初入库单自动生成** | 含库存/金额的导入完成后，系统自动生成期初入库单，便于后续核对与审计 |
| 6 | **多仓库分仓导入** | 多仓库场景下，按仓库分别准备 Excel、分别执行导入（每次对应一个目标仓库） |
| 7 | **导入校验与错误反馈** | 对必填项缺失、编码重复、仓库/类型不存在、Excel 含公式等情况给出明确提示 |
| 8 | **基础参数前置引导** | 导入前需在「系统设置 → 参数设置」中维护仓库、货品类型等基础数据 |

---

## 四、交付后您能获得什么

- **快速上线**：成百上千条货品可在一次或少数几次导入中完成建档，无需逐条手工录入  
- **期初库存一次到位**：初始数量与金额同步进入系统，并自动生成期初入库记录，财务与仓库可据此核对  
- **多仓各管各的**：主仓、门店仓、备件仓等可分别整理、分别导入，库存归属清晰  
- **操作有章可循**：官方模板 + 填写说明 + 错误提示，业务人员可自行完成大部分导入工作  
- **降低差错率**：导入前系统自动校验，减少因名称不一致、仓库未建、编码重复导致的数据混乱

## 五、分阶段说明

### 第一阶段：基础准备（导入前）

- 在「系统设置 → 参数设置」中完成 **仓库信息**、**货品类型** 等基础配置  
- 如需自定义扩展字段，须先在参数设置中定义后再出现在模板中  
- 实施顾问或仓库管理员下载官方模板，按业务实际情况整理 Excel  

### 第二阶段：单仓库初始导入（本次交付核心）

- 进入 **货品管理 → 导入 → 导入货品信息**  
- 上传整理好的 Excel 文件  
- 系统校验通过后写入货品档案；若含库存/金额，则写入库存并 **生成期初入库单**  
- 核对导入结果与期初入库单数据  

### 第三阶段：多仓库分仓导入（本次交付核心）

- 按仓库拆分 Excel（例如：主仓一份、门店仓一份）  
- **每次导入选择一个目标仓库**，分别上传各仓数据  
- 各仓分别生成对应的期初入库记录  
- 全部仓库导入完成后，在库存查询中分仓核对  

### 第四阶段：验收与培训（7 月 15 日前完成）

- 完成试导入与正式导入演示  
- 确认错误提示、期初单生成、多仓分导等关键场景  
- 交付简要操作说明（含注意事项）

## 六、重要注意事项（请提前知晓）

1. **货品名称为必填项**；编码可不填，系统会自动生成，但填写后须保证不重复  
2. **填写了库存数量或金额的货品，必须填写「所在仓库」**，且仓库名称须与系统中已建仓库完全一致  
3. **货品类型、所在仓库须提前在参数设置中维护**，否则导入会失败  
4. **Excel 中不要使用计算公式**，须将结果复制为数值后再导入  
5. **期初库存与金额通常只能导入一次**；再次导入不会覆盖或累加已有期初数据，如需修正请通过正常入库/调整流程处理  
6. **多仓库场景请分仓、分次导入**，不建议在同一批次中混导多个仓库的数据

## 七、交付与验收说明

开发完成后，建议按以下步骤确认：

1. **参数准备**：确认至少已创建 1 个仓库、1 种货品类型  
2. **模板下载**：在货品管理页面成功下载导入模板  
3. **试导入（不含库存）**：导入 3～5 条仅含基本信息的货品，确认列表可见、编码规则正确  
4. **试导入（含期初）**：导入含「数量 + 金额 + 所在仓库」的货品，确认库存正确、期初入库单已生成、平均成本已计算  
5. **多仓分导**：若有多个仓库，分别导入两个仓库各 2～3 条数据，确认库存归属正确、互不混淆  
6. **异常校验**：故意上传一条缺少名称或仓库不匹配的数据，确认系统给出清晰错误提示  
7. **公式拦截**：上传含 Excel 公式的文件，确认系统拒绝或提示转换  

以上步骤均可正常完成，即视为本次开发验收通过。如有疑问或发现与预期不符之处，请及时反馈，我们将在后续迭代中跟进处理。
